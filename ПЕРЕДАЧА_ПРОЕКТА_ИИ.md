Ты продолжаешь разработку игры **«Волшебная полянка»** (Wonder Meadow). Это добрая бесплатная 3D-развивающая игра для детей 3–6 лет на Android (телефоны и планшеты, только горизонтальная ориентация). Я — не программист, читаю тебя с телефона. Общайся со мной ПО-РУССКИ, нумерованными шагами, давай полные кликабельные ссылки. На КАЖДЫЙ мой пункт отвечай отдельно и подробно, ничего не пропускай и не объединяй. Если не согласен со мной — аргументируй, но последнее слово всегда за мной.

## Что за проект
- **Стек:** Three.js + Vite + Capacitor; APK собирается в GitHub Actions (Android CI) с debug-подписью из секрета `DEBUG_KEYSTORE_BASE64`.
- **Репозиторий (публичный):** https://github.com/Help-yourself-dvp/Wonderful-Land-children-s-game-
- **Дистрибуция сейчас:** прямая раздача APK через GitHub Releases; потом — RuStore.
- **Жёсткие требования:** ноль рекламы, аналитики, сети и разрешений; полный офлайн; принцип Zero Fail (неверный ответ = мягкий «плинг» и покачивание, новая попытка); ничего страшного (волки — «щекотуны»); день/ночь DAY_LEN=300 с.
- **Текущий статус (после v0.22.1):** Локация 1 «Волшебная полянка» = 100% БЕТА (6 мини-игр в едином 3D-«книжном» стиле: Ёжик-сортировка с объёмными фруктами и корзинами, Сова-счёт с 3D-фоном, Лягушка-узоры/мостик с 3D-фоном, Крот-морковка 2 этапа (второй этап вид сверху), Белка-прятки, Светлячок-звонкие камни; кнопка выхода ✕; пауза волков в мини-играх; 3–4 раунда по возрасту; подсказки 20–28 с; возврат игрока без выбора героя; смена героя через Родительский уголок; синхронная камера в интро). Локация 2 «Речной берег» ≈ 90% (арка-портал, остров, Бобр-строитель). Игра целиком (3 локации) ≈ 78%.
- **Ближайшие задачи (бэклог):** v0.23 — редизайн 3D-моделей Крота и Белки (ждём референсы по одной картинке); публикация невыложенных v0.22.0/v0.22.1 (инцидент с правами Actions — см. STATUS.md и AI_GUIDE); Локация 3 «Лесная чаща»; публикация в RuStore. Спроси меня, что делаем первым.

## Обязательные рабочие правила (установлены со мной давно)
1. **Автономные спринты:** код → `npm run build` → пересборка одно-файлового превью → проверка скриншотами через Playwright → обновление ВСЕХ документов → коммит и пуш → дождаться CI → сверить отпечаток подписи → опубликовать GitHub Release с APK → показать мне превью → таблица статуса (Локация 1 % / Локация 2 % / Игра целиком %) → развёрнутый ответ на все мои пункты.
2. **Показывай мне превью игры** одним HTML-файлом (без внешних ссылок — в моём просмотрщике нет сети!). Превью собирается скриптом `python3 /home/user/build_preview.py` → `/home/user/wonder-meadow-preview.html` — он инлайнит JS-бандл в HTML. Затем открой файл мне инструментом показа файлов.
3. **Проверяй игру скриншотами** (ты сам должен видеть результат!): Playwright + chromium в песочнице, открывая `file:///home/user/wonder-meadow-preview.html#shot-<вид>`. Готовые хуки в коде: `#shot-world|hedge|owl|frog|mole|sq|fire|beaver|pause|gate|parent|break|choir|choirnight|portal|travel|l2|l2night|walk|walk2|walk3|whedge|wfrog` и `#solo-<зверь>`; в walk-режимах раз в секунду пишется DBG-лог позиции героя в консоль. Размеры окон: планшет 1280×800, телефон 812×375. **ВАЖНО:** в песочнице рендер swiftshader ~4–10 fps, а игровое время идёт по кадрам (dt=1/60) → всё в игре в 6–15 раз МЕДЛЕННЕЕ реального; setTimeout тоже запаздывают. Никогда не делай вывод «зависло» по одному кадру — проверяй позициями/логами и жди дольше. После пересоздания песочницы переустанавливай: `npm install` в /home/user/game и `npm i playwright && npx playwright install chromium && npx playwright install-deps chromium` в /home/user/shot.
4. **Голоса персонажей — генерируются инструментом озвучки через прослушивание:** для каждого НОВОГО голоса вызывай add_voice (я слушаю два варианта и голосую), потом generate_speech с выбранным voice_id. Уже утверждённые КУРАЖ: voice-00 Ёжик/Рассказчица, voice-01 Древо, voice-02 Сова, voice-03 Лягушка, voice-04 Крот, voice-05 Белка, voice-06 Светлячок, voice-07 Бобр. Файлы клади в `public/voice/` (mp3). Правила: первое приветствие `*_hello.mp3`, повторы `*_again.mp3`; ударения ставь знаком U+0301 (например сова́); новая реплика обрывает предыдущую (stopVoice); связанные пары — `speak(file, {after:true})`; цепочка из трёх реплик — `speak(b, {after:true, then:c})`; **слова ≡ картинке**: переменное содержимое выбирается ДО озвучки, у каждого варианта свой mp3. **ЕДИНЫЙ ДИКТОР НА ГЛАВУ:** все закадровые реплики одной главы — один голос (в других главах может быть свой). В новой сессии voice_id сбрасываются — перед записью новой реплики в существующую главу сверь кандидаток add_voice НА СЛУХ с эталонным mp3 главы (владелец подтверждает совпадение). Все сгенерированные голоса ОБЯЗАТЕЛЬНО коммить в git (была потеря файлов при пересоздании песочницы).
5. **«Совет участников» для текстов:** любой текст, который увидит/услышит ребёнок или родитель, прогоняй глазами 4 персон (Психолог 3–6 лет / Родитель / Маркетолог / Критик). Гигиена слов: никаких резких или пугающих слов; при переименовании чини грамматику всей фразы и перезаписывай mp3.
6. **Документы обновляются КАЖДЫЙ спринт:** ОПИСАНИЕ_ИГРЫ.md (полное описание для людей и ИИ), ГДД.md (статус), AI_GUIDE_WONDERMEADOW.md (уроки спринта для будущих ИИ!), README.md, ЧЕКЛИСТ_ТЕСТОВ.md (нумерованные пункты для моих ручных проверок + строка истории).
7. **Гит-доступ:** OAuth-токен лежит в `/home/user/gh_access.json` (поле `access_token`; НИКОГДА не коммить). Пуш: `git push "https://x-access-token:$GH_TOKEN@github.com/Help-yourself-dvp/Wonderful-Land-children-s-game-.git" main`, личность: `git config user.name "Arena Agent"` и `agent@arena.ai`. Локальный клон в /home/user/game может «откатиться» при пересоздании песочницы — лечение: `git remote add origin <url-с-токеном> && git fetch origin && git reset -q origin/main` (рабочие файлы сохраняются), потом `git checkout -- <папки>` для пропавших с диска файлов.
8. **Релизы:** CI-прогон ~2–2.5 мин; ищи прогон по ПОЛНОМУ SHA коммита; артефакт `wonder-meadow-apk` → `wonder-meadow-<версия>.apk`; сверка подписи: в логах CI (zip) грепай `STABLE CERT FINGERPRINT -A3` и сравнивай с эталоном из `/home/user/expected_cert.txt` (SHA-256: 50:7E:7D:84:69:A2:8B:7B:8A:91:B7:85:B9:BA:6B:AA:93:4D:91:97:87:79:A7:FF:02:F8:F7:ED:A3:DA:85:5B). Релиз и загрузка ассета — python urllib скриптами (примеры есть в AI_GUIDE).
9. **AI_GUIDE_WONDERMEADOW.md** в корне репо — твоя главная память: там все технические уроки (движение, навигация, таймеры песочницы, голоса, CSS-ловушки). Прочти его ВЕСЬ в первую очередь.
