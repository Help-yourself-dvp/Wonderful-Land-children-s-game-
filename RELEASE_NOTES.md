## Что нового в v0.17.1

- Сюжет Полянки теперь развивается по понятной цепочке: ребёнок сначала хотя бы один раз помогает **всем шести друзьям**.
- После этого Рассказчица говорит: «Когда решишь двигаться дальше, зайди ещё раз к Кроту — кажется, у него есть особое задание для тебя».
- Следующий визит к Кроту запускает особое повторное задание. Только его завершение открывает светящийся ручеёк к Древу и следующий сюжетный шаг с поливом.
- Ранний визит к Кроту больше не завершает главу раньше времени. При этом повторять задания Крота и любого другого друга по-прежнему можно сколько хочется.
- Старые сохранения не стираются: уже открытый ручеёк остаётся на месте, а пройденные друзья учитываются.
- Добавлены две новые озвученные реплики: приглашение Рассказчицы и особая фраза Крота.
- Версия на заставке, в Родительском уголке и в системной информации Android теперь берётся из одного файла `version.txt`. Для этой сборки везде должно быть **0.17.1**.

## Безопасность

Игра полностью работает **офлайн**, не содержит рекламы, покупок и аналитики, не собирает данные и не запрашивает разрешения Android.

## Установка

Скачайте файл `wonder-meadow-0.17.1.apk` ниже и откройте его на Android-устройстве. Версия устанавливается поверх v0.9.1 и новее с сохранением прогресса. При переходе с v0.9.0 и более ранней версии старое приложение нужно один раз удалить из-за прежней подписи.
