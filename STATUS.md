## Открытый инцидент: релизы v0.22.x не публикуются
- Сборка и подпись APK проходят успешно (отпечаток сертификата совпадает с эталоном), но шаг «Publish GitHub Release» падает с `exit code 1`.
- Причина: в Settings → Actions → General → Workflow permissions стояло «Read repository contents permission». Владелец переключил на «Read and write permissions».
- Требуется: повторно запустить последний прогон (`32102359298`) через **Re-run all jobs** или опубликовать релиз `v0.22.1` вручную, приложив APK из артефакта.
- Обходной путь для следующих ИИ: если не работает `gh release create` из CI — проверь Workflow permissions; правки `.github/workflows/*.yml` требуют права `workflows`, которого у GitHub App нет — делай PR и проси владельца подтвердить.
