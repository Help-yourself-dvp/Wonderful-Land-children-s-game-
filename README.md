# Волшебная полянка 🌳

Детская развивающая 3D-игра для Android (3–6 лет). Офлайн, без рекламы,
без покупок, без сбора данных. Бесплатно.

- 📖 Полное описание игры (для людей и ИИ): [ОПИСАНИЕ_ИГРЫ.md](ОПИСАНИЕ_ИГРЫ.md)
- 🤝 Правила работы с ИИ: [AI_GUIDE_WONDERMEADOW.md](AI_GUIDE_WONDERMEADOW.md)

## Что уже в игре (v0.13.0, поздняя альфа)

Прогулка по сказочной полянке, добрые персонажи дают развивающие задания:
🦔 Ёжик — сортировка урожая; 🦉 Сова — счёт до 5; 🐸 Лягушка — узоры-логика;
🐾 Крот в каске — «Верни морковку!» (внимание и реакция); 🐿️ Белка —
«Прятки-норки» (память: где орех под грибочком?); ✨ Светлячок —
«Звонкие камни» (слуховая память: повтори песенку на светящихся камушках-нотках).
У героев разные походки: Зайка прыгает, Лисёнок бежит, Мишка переваливается.
Награда — волшебные капельки 💧, которыми выращивают Древо Желаний.
Сказка растёт главами: победа у Крота открывает главу 1 «Корешок-ручеёк», а помощь
всем шестерым жителям — **главу 2 «Звонкое созвучие»**: друзья поют хором у Древа,
и его звезда засияет для всей полянки (гало, маяк, ночной хоровод огоньков).
Альбом наклеек, день/ночь, волки-щекотуны (не страшные!), домик-укрытие, пауза,
полная озвучка разными голосами — слова всегда совпадают с картинкой.
Готово: **все 6 игр Локации 1 + две главы сказки** ✔ (дальше — «Родительский уголок», затем бета).

## Технологии

Three.js + Vite, упаковка в Android через Capacitor.
APK собирается автоматически в GitHub Actions при каждом пуше в `main`
(см. Actions → последняя успешная сборка → артефакт `wonder-meadow-apk`).
Версия берётся из `version.txt`.

## Локальный запуск (для разработчика)

```bash
npm install
npm run dev
```
