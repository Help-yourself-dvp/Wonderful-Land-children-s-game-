# Волшебная полянка 🌳

Детская развивающая 3D-игра для Android (3–6 лет). Офлайн, без рекламы,
без покупок, без сбора данных. Бесплатно.

- 🤝 Правила работы с ИИ: [AI_GUIDE_WONDERMEADOW.md](AI_GUIDE_WONDERMEADOW.md)

## Что уже в игре (v0.21.0, **Локация 1 = БЕТА + Локация 2 почти полная!** 🌉)

> **v0.21.0 — удобство и разнообразие:** в каждой мини-игре есть кнопка выхода ✕ (ставит мир на паузу); волки не бегают во время заданий; мини-игры длиннее по возрасту (3–4 раунда); подсказки появляются позже (20–28 с); игра запоминает выбранного героя и не заставляет проходить вступление заново; окна крупнее (~80% экрана); у Крота крупнее морковка и исправлен второй этап.
>
> **v0.20.0 — забота о маленьких игроках:** экран не гаснет во время вступления и сказки (Wake Lock + Android FLAG_KEEP_SCREEN_ON, без разрешений); мини-игра Лягушки получила сказочный горизонтальный фон; предметы Совы всегда в границах поля; убраны повторы одного и того же подряд у Совы и Белки.
>
> **v0.19.0 — первая проба нового сказочного визуала:** игра Ёжика стала горизонтальной авторской сценой 16:9 с крупным добрым героем, осенним фоном и настоящими интерактивными плодами и корзинами. Плоды, стрелки и плетение нарисованы собственными CSS-формами и не зависят от emoji-шрифтов Android. Общие тёплые объёмные рамки распространены на остальные мини-игры, а интерактивный 3D-мир сохранён.
>
> **v0.18.0 — новый Альбом приключений:** 24 награды на двух страницах. Каждый успешный полив Древа открывает следующую наклейку, а карточка и цифра на кнопке сразу сообщают о подарке вне альбома. Наклейка приклеивается только в своё место; неверное место мягко подсказывает попробовать ещё. Первая страница даёт 12 целей, хотя сюжет требует лишь познакомиться с шестью друзьями, поэтому любимые задания хочется повторять.
>
> **v0.17.1 — добрая сюжетная цепочка Крота:** сначала ребёнок хотя бы раз помогает всем шести друзьям Полянки. Затем Рассказчица предлагает вернуться к Кроту, следующий визит запускает особое задание, и только после него появляется ручеёк к Древу. Повторять задания любого друга можно в любое время.
>
> **v0.17.0 — авто-сложность по возрасту:** на первой заставке и в Родительском уголке выбирается возраст (3–4 / 5–6 лет), и все задания подстраиваются сами: счёт до 5 или 9, больше плодов, длиннее узоры и песенки, больше норок и дощечек. Zero Fail и подсказки 💡 — на обоих уровнях.
> **v0.16.0 — Лягушка прискакала на речку!** Новая игра «Речные камушки» 🌺: продолжи узор из цветных камушков (2 раунда для 3–4 лет, 3 и более длинные ряды для 5–6 лет). Та же любимая Лягушка — с розовой заколкой-кувшинкой.
> **v0.15.1 — хотфикс по живому тесту Локации 1:** стартовая кнопка ▶ «нажми — и пойдём играть!» для нечитающих; идеально плавное движение героя; честная кнопка 🔇 (гасит и голоса); альбом на весь экран с ✖; игра замолкает и замирает при сворачивании; Крот зовёт на большое поле 3×3 после ряда норок; карта глав сказки 🗺️; у Ёжика — грядки, у Лягушки — мостик; зверята крупнее; сброс прогресса с красивым подтверждением «Сказка начинается сначала…».

Прогулка по сказочной полянке, добрые персонажи дают развивающие задания:
🦔 Ёжик — сортировка урожая; 🦉 Сова — счёт до 5; 🐸 Лягушка — узоры-логика;
🐾 Крот в каске — «Верни морковку!» (внимание и реакция); 🐿️ Белка —
«Прятки-норки» (память: где орех под грибочком?); ✨ Светлячок —
«Звонкие камни» (слуховая память: повтори песенку на светящихся камушках-нотках).
У героев разные походки: Зайка прыгает, Лисёнок бежит, Мишка переваливается.
Награда — волшебные капельки 💧, которыми выращивают Древо Желаний.
Сказка растёт главами: после первой помощи всем шестерым друзьям Рассказчица зовёт
ещё раз зайти к Кроту. Его особое повторное задание открывает главу 1
«Корешок-ручеёк», а дальнейший рост Древа — **главу 2 «Звонкое созвучие»**:
друзья поют хором, и звезда засияет для всей полянки. Сияние звезды открывает **волшебную арку** —
за ней **Локация 2 «Речной берег»**: речка с бликами, настоящий мостик с перильцами
(по нему ходят!), ивы, камыши, стрекозы и **🦫 Бобр-строитель** с игрой
«Дощечки для мостика» (геометрические формы: круг, квадрат, треугольник, прямоугольник).
Альбом приключений с 24 наклейками на двух страницах и точными местами для каждой награды,
день/ночь на обеих локациях, волки-щекотуны (не страшные!), домик-укрытие,
удобная пауза с большой кнопкой «Играем дальше!», полная озвучка 8 разными голосами —
слова всегда совпадают с картинкой.
**👪 Родительский уголок** (из паузы, через пример-дверку): статистика «Как малыш растёт»,
мягкий таймер отдыха (полянка засыпает вместе с малышом), сброс прогресса.
Всё локально, без сети и рекламы.
Готово: **Локация 1 на 100% — БЕТА** ✔ **Локация 2 ≈ 90%** (арка, Бобр, речная Лягушка) ✔ **Авто-сложность по возрасту** ✔ **Сюжетный gate Крота** ✔ Дальше — полировка речной Лягушки и узоров, затем Локация 3 «Лесная чаща».

## Технологии

Three.js + Vite, упаковка в Android через Capacitor.
APK собирается автоматически в GitHub Actions при каждом пуше в `main`
(см. Actions → последняя успешная сборка → артефакт `wonder-meadow-apk`).
Ручной запуск workflow умеет по флагу `publish_release` сразу опубликовать APK в GitHub
Release — это резервный путь при сбое скачивания Actions artifact. Версия берётся из
`version.txt`, заметки выпуска — из `RELEASE_NOTES.md`.

## Локальный запуск (для разработчика)

```bash
npm install
npm run dev
```
